# Predire-si-un-client-va-souscrire-a-une-offre-

🎯 Prédire si un client va souscrire à une offre 🏦

📊 Projet personnel de Data Science 

Cette étude est une étude de classification binaire qui porte sur la prédiction à la souscription à une offre bancaire à partir des informations disponibles dans le Bank MarketingDataset.

Dans cette étude, nous construisons, comparons et interprétons les résultats de plusieursmodèles prédictifs capables prédire si un client va souscrire à l’offre à partir de ses caractéristiques personnelles, sa situation financière et des informations de la campagnemarketing.

Le travail comprend notamment le traitement des valeurs manquantes, le traitement desvaleurs aberrantes, l’analyse des corrélations, la création de nouvelles variables, l’encodagedes variables catégorielles, l’entraînement de plusieurs modèles de machine learning et lacomparaison de leur performance sur un ensemble de validation indépendant, l’explicationSHAP à trois niveaux des résultats de prédictions, etc.

Les modèles utilisés pour les prédictions sont notamment : XGBoost classifier et LightGBMclassifier.
